# What's New With 4.8.0

CBOrm 4.8.0 focuses on dependency updates, BoxLang improvements, and enhanced multi-JDK testing.

## Added

### Dependency Management

* **CommandBox Standards**: Refreshed all dependencies to align with new CommandBox package management standards

### BoxLang Enhancements

* **Intelligent Autocasting**: BoxLang's smarter autocasting capabilities are now leveraged - CBOrm passes values through directly when running on BoxLang, improving performance and type safety

### Testing Infrastructure

* **Multi-JDK Testing**: Automated testing now runs on each JDK version that the supported CFML engines require, ensuring compatibility across different Java environments

## Release Date

April 8, 2025
