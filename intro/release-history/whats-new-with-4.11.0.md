# What's New With 4.11.0

CBOrm 4.11.0 is a minor release with documentation improvements and CI/CD updates.

## Added

### Documentation & Developer Experience

* **Comprehensive Documentation Links**: Added extensive documentation references throughout the codebase for better developer experience
* **Dependabot Integration**: Automated dependency management to keep the project secure and up-to-date
* **Copilot Instructions**: Added AI coding assistant instructions to help developers contribute more effectively

### CI/CD Improvements

* **GitHub Actions Updates**: Refreshed and modernized all GitHub Actions workflows for better automation and reliability

## Release Date

September 11, 2025
