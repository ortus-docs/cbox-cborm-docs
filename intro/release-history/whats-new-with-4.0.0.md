# What's New With 4.0.0

CBOrm 4.0.0 is a major release with breaking changes.

{% hint style="danger" %}
**Breaking Changes**: CBOrm 4.0 requires Adobe ColdFusion 2023+ and drops support for Adobe ColdFusion 2021 and earlier.
{% endhint %}

### Added

* Upgraded all dependencies to major bumps

### Changed

* Dropped ACF2016 Support
