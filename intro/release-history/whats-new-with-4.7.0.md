# What's New With 4.7.0

CBOrm 4.7.0 introduces BoxLang certification and automated testing support.

## Added

### BoxLang Support

* **BoxLang Certification**: Official certification for BoxLang - CBOrm is now fully tested and supported on the BoxLang runtime
* **Automated BoxLang Testing**: Continuous integration now includes automated testing against BoxLang to ensure ongoing compatibility

{% hint style="info" %}
BoxLang is a modern, dynamic JVM language fully compatible with CFML. CBOrm now officially supports BoxLang alongside Adobe ColdFusion and Lucee.
{% endhint %}

## Release Date

March 26, 2025
